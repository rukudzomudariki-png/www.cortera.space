# Accessibility (WCAG 2.2 AA)

Playwright + axe-core tests over every route at 375 and 1280 widths, dark and paper sections. Zero serious/critical violations target.

## Manual-equivalent scripted checks
- Full keyboard traversal of nav (desktop and mobile overlay), mega panel, topic rows on /contact, copy buttons, filter chips, card links
- Visible focus on every interactive element
- Skip link works
- No keyboard traps
- Focus returns correctly when mobile overlay and mega panel close

## Known limitations
- Forced-colors mode legibility verified manually
- 200% text zoom and 320px reflow no horizontal scroll
